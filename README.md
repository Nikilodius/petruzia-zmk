# PetruziaMini ZMK configuration

This configuration targets a Pro Micro-shaped nRF52840 controller using the
GPIO labels supplied by the builder.

Columns: P1.00, P0.24, P0.22, P0.20, P0.17, P0.31, P0.29, P0.02, P1.15, P1.13.
Rows: P1.11, P0.11, P1.04, P1.06.

The diode direction is COL2ROW. Verify the wiring before flashing.
